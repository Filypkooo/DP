# Hlboké ensemble metódy v detekcii online toxicity v textoch zo sociálnych médií
Táto práca sa zameriava na klasifikáciu TRUE/FAKE textov s využitím klasických metód strojového učenia, rekurentných neurónových sietí a ensemble modelov. 

## Obsah repozitára
Datasety a zdrojové kódy sú uložené v dvoch samostatných komprimovaných archívoch (.rar).

## Použité metódy 
TF-IDF vektorizácia textu
Random Forests
XGBoost
LSTM
GRU/BiLSTM
Ensemble metódy (bagging, boosting)
