# Hlboké ensemble metódy v detekcii online toxicity v textoch zo sociálnych médií
Táto práca sa zameriava na detekciu online toxicity v (TRUE/FAKE) textoch zo sociálnych médií pomocou klasických metód strojového učenia, rekurentných neurónových sietí a ensemble modelov.

## Obsah repozitára
Dataset a zdrojové kódy sú uložené v dvoch samostatných archívoch (.rar).

## Použité metódy
- TF-IDF vektorizácia textu  
- Random Forests 
- XGBoost  
- LSTM  
- GRU / BiLSTM  
- Ensemble metódy (bagging, boosting)
